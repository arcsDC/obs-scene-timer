# obs-scene-timer

An OBS Studio Lua script that automatically cycles through a list of scenes on a configurable timer for hands-free presentations.

## Stack

Primary language: **Lua**

## Project structure

- `obs-scene-timer.lua` — Automates scene switching in OBS Studio based on a fixed interval.
- `config.json` — scene names and timer settings

## Usage

Review the source files and install any dependencies referenced by the project before running it.
